الطريقة الأسهل والأضمن 100% GitHub Cloud APK

1. البناء السحابي بملفين فقط (بدون gradlew أو Capacitor)

تجنّب نهائياً أخطاء gradlew not found أو Java 21! هذا الـ Workflow الذكي يأخذ ملف index.html فقط، ويقوم داخل سيرفر GitHub بإنشاء مشروع الأندرويد الأصلي وبناء ملف app-debug.apk جاهز للتحميل في دقيقتين.

  • ✅ لا يحتاج لرفع مجلدات معقدة (فقط index.html + main.yml)
  • ✅ يدعم العربي، LocalStorage، الواتساب، والطباعة
  • ✅ يولّد الأيقونة تلقائياً ويخرج ملف APK مباشر
حزمة متكاملة Native WebView ZIP

2. حزمة مشروع أندرويد الكاملة (.ZIP)

تحتوي على مشروع أندرويد جاهز بالكامل مع ملف index.html الخاص بك، وكود MainActivity.java، وملف AndroidManifest.xml، والأيقونة المولّدة، وملف البناء التلقائي.

  • 📦 app/src/main/assets/index.html
  • 📦 MainActivity.java + AndroidManifest.xml
  • 📦 أيقونات ic_launcher.png + build.gradle
تثبيت فوري بدون انتظار PWA / WebAPK

3. حزمة تطبيق ويب تقدمي يعمل بدون إنترنت (PWA)

توليد حزمة تضم manifest.json ومحرك التخزين المؤقت sw.js والأيقونات، لتثبيت التطبيق فوراً على شاشة الهاتف الرئيسية عبر متصفح Chrome بدون الحاجة لتصريح مصادر غير معروفة.

  • ⚡ يعمل 100% بدون إنترنت بعد الفتح الأول
  • ⚡ يظهر بأيقونة مستقلة وبملء الشاشة على الهاتف
  • ⚡ جاهز للرفع المجاني على GitHub Pages أو Netlify
